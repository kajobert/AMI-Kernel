# AMI-Kernel

> **Trust instead of Authority.**

AMI-Kernel is the future orchestration/runtime capability of [AMI — Artificial Mind Full Intelligence](https://github.com/kajobert/AMI).

This repository is intentionally bootstrap-stage. Architecture will be refined by AMI archaeology and validated implementation work rather than by copying historical assumptions forward.

## Intended responsibilities

- orchestration of AMI capabilities and events;
- model/inference routing as replaceable tooling rather than identity;
- bounded execution and state handoff;
- interfaces for Guardian, Observatory and self-improvement loops;
- integration with AMI Knowledge Core and AMI Protocol.

**Status:** DESIGN / bootstrap.

See the umbrella repository for the AMI Repository Standard, licensing policy, public/private boundary and contribution rules.
